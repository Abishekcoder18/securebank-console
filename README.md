# SecureBank Console Application

A console-based banking application developed in Python as part of the Python Backend Developer course.

## Features Completed

### Week 1
- Create Account
- Deposit Money
- Withdraw Money
- Check Balance
- Close Account
- Custom Exceptions
- CLI Menu

### Week 2
- Transaction History
- Money Transfer
- Atomic Transfer Rollback
- Reverse Last Transaction
- Customer Account Search using defaultdict

## Technologies Used

- Python 3
- Dataclasses
- Dictionary
- defaultdict
- Custom Exceptions

## Concepts Covered

- Object-Oriented Programming
- In-Memory Data Storage
- Transaction Management
- Dictionary Indexing
- Exception Handling
- CLI Application Development
